# Optimus public showcase

Static architectural showcase for [Optimus](https://github.com/Murathanx12/Optimus), built by [Murathan Abdullaev](https://murathan.info). This directory is the versioned deployment source.

No build dependencies, backend, inference calls, tracking or private corpus. Serve this directory with any static host. Only `index.html`, `style.css`, `script.js`, `mark.svg` and `vercel.json` are required for deployment. Vercel project identity stays in the ignored `.vercel/` directory.

The diagram is explanatory and its selectable evidence examples are synthetic. Aggregate collection receipts describe a checked 18 October 2026 run; they are not a public export of its private source material. Tool counts are checked installation counts, not guaranteed stable APIs.

Before publishing, verify responsive layout, keyboard focus, the three example buttons, link destinations and the absence of private files. Keep previous generated brain exports outside this deployment.
