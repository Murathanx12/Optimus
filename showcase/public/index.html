Useful work accumulates across repositories, documents and conversations. Optimus keeps that context in readable files and exposes focused tools to retrieve it.

The assistant reasons about the evidence. Optimus supplies the records, sources and reusable procedures. It is a memory and tool system, rather than a newly trained foundation model.

What about ChatGPT on the web?

Local stdio configuration serves compatible local clients. ChatGPT.com needs a separate supported connection, such as Secure MCP Tunnel, with the right account permissions and authentication. The public website is a showcase, not an endpoint into the private brain.

Official Secure MCP Tunnel documentation

Keep the private part private.

The public engine and this architectural demonstration are separate from the owner's knowledge store. No chat export, browser session, personal context or private research corpus is bundled here. Retrieved material still needs source checks; accumulated text does not establish accuracy on its own.
